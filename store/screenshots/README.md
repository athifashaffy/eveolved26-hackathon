# Store screenshot capture plan

Use synthetic data labelled **Demo Data** only. Locale: `en-CA`; release:
`1.0.1+8`; light mode; text scales 1.0 and 1.3.

Capture onboarding, baseline learning, Today with confidence, 30-day Trends,
Ask Signa grounded explanation, and the clinician-summary entry point. Do not
capture real health data, profile details, private notes, or a crisis question.

Required targets: current App Store 6.9-inch and 6.5-inch iPhone sizes plus a
current Play phone portrait size. Verify no overflow, debug banner, clipped
copy, or touch target below platform guidance before approving each PNG.
